### 4. Search-engine foundations

The package includes:

* a consistent page title and visible heading;
* accurate meta descriptions;
* canonical URLs;
* Open Graph and social-sharing metadata;
* `Person`, `WebSite`, `WebPage`, `CreativeWork` and breadcrumb JSON-LD;
* your canonical name and alternate name;
* links connecting the portfolio, LinkedIn and GitHub;
* `robots.txt`;
* `sitemap.xml`;
* a web manifest;
* a custom 404 page;
* descriptive URLs for each case study;
* a branded social-sharing image.

Google may use the page title, visible main heading, Open Graph title, page content and link text when generating search-result titles. Structured data can help Google understand a page but does not guarantee a ranking or rich result. The site therefore aligns all of these signals instead of relying on keyword repetition. ([Google for Developers][1])

LinkedIn states that public profiles are periodically reviewed by search engines and that public visibility, a complete profile and regular substantive updates support indexability. Search engines may still take several weeks to reflect changes. ([LinkedIn][2])

## Important integrity decisions

### Your existing employment-date conflict was not silently resolved

The CV says discoverIE began in **September 2024**, while LinkedIn shows **September 2025**.

The new portfolio therefore says **“Current role”** without displaying a start date. We should add the exact date only after it is confirmed and corrected everywhere.

### Credentials are shown by status

The portfolio currently identifies:

* PL-300 — **In progress**
* DP-600 — **In progress**
* FMVA — **In progress**
* DAMA/CDMP Associate preparation — **In progress**
* Microsoft AI Business Professional — **Planned**

BIDA is not promoted on the homepage because it is not currently active and would weaken the priority message.

### Current work is labelled accurately

The site uses language such as:

* supporting;
* contributing;
* developing;
* evaluating;
* translating requirements;
* assisting with implementation.

It does not use:

* principal architect;
* transformation lead;
* enterprise owner;
* certified professional before certification;
* unsupported percentage improvements.

### Confidentiality has been protected

The portfolio does not disclose:

* internal financial values;
* company-specific mappings;
* system credentials;
* access methods;
* production architecture;
* internal screenshots;
* security arrangements;
* identifiable operating-company data.

The future public Power BI and Fabric demonstrations should use synthetic companies and synthetic financial information.

### A monogram is being used instead of the current website photographs

The existing website photographs are not suitable for the new professional positioning, and the LinkedIn screenshot does not contain a sufficiently high-resolution version of your professional headshot.

The site therefore uses a clean `BM` identity until the original professional headshot is available.
